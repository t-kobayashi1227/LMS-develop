# カテゴリ管理機能

## 概要

管理者がコースカテゴリを自由に追加・編集・削除できる機能。
管理者の設定ページ（`/admin/settings`）に「カテゴリ管理」ボタンを設置し、クリックするとモーダルを開いてCRUD操作を行う。

## ステータス

✅ 実装完了

## 背景・課題

- カテゴリは `course_categories` テーブルでDB管理されているが、管理UIが存在しない
- 初期データの4件（AI Basics / AI Applications / Design / Marketing）しか選べない状態

## 制約・仕様

- カテゴリ名は重複不可
- コースが紐づいているカテゴリは削除不可（削除しようとするとエラーメッセージを表示）
- フロントエンドの catch-all プロキシ（`app/api/admin/[...path]/route.ts`）が全HTTPメソッドに対応済みのため、新規プロキシ作成は不要

## UI 仕様

### 設定ページ上の表示

設定ページにはカテゴリ件数と「カテゴリ管理を開く」ボタンのみ表示する。カテゴリ一覧はモーダル内でのみ表示する。

```
┌──────────────────────────────────────┐
│ カテゴリ管理                           │
│ コースカテゴリを管理します。現在 4 件    │
│                  [カテゴリ管理を開く →] │
└──────────────────────────────────────┘
```

### モーダル内の表示

```
┌─────────────────────────────┐
│ カテゴリ管理          [× 閉じる] │
│                              │
│  AI Basics       [✏] [🗑]   │
│  AI Applications [✏] [🗑]   │
│  Design          [✏] [🗑]   │
│  Marketing       [✏] [🗑]   │
│                              │
│  [新しいカテゴリ名     ] [追加] │
└─────────────────────────────┘
```

### 編集操作

- 鉛筆アイコンのクリック、またはカテゴリ名のダブルクリックで編集モードに入る
- 編集中は Enter キーで保存、Escape キーでキャンセル

## DB スキーマ（既存）

```
course_categories
  id            int
  name          varchar  ← 表示名
  slug          varchar  ← URL用識別子（name から自動生成）
  sort_order    int      ← 登録順に自動採番
  created_at    timestamp
  updated_at    timestamp
```

## API 設計

バックエンドのエンドポイントはすべて `/api/v1/` プレフィックス付き。認証済み管理者のみアクセス可。

| メソッド | エンドポイント | 説明 |
|---------|--------------|------|
| GET | `/api/v1/admin/categories` | 一覧取得（実装済み） |
| POST | `/api/v1/admin/categories` | 新規作成 |
| PUT | `/api/v1/admin/categories/{id}` | 名前を更新 |
| DELETE | `/api/v1/admin/categories/{id}` | 削除（使用中コースがある場合は 422 を返す） |

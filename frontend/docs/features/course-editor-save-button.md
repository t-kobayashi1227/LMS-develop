# コース編集画面 — 保存ボタン追加

## 概要

コース編集画面（`/admin/courses/[courseId]`）の下部にも保存ボタンを追加する。

## ステータス

✅ 実装完了

## 背景・課題

- 保存ボタンが画面上部にしか存在しない
- チャプター・レッスンを編集した後、保存するために画面上部までスクロールする必要がある
- 受講生一覧（`CourseEnrollments`）の直上に保存ボタンを追加することで操作性を改善する

## ページ構造

```
/admin/courses/[courseId]  （page.tsx — Server Component）
  ├── <CourseEditor />         ← 保存ボタン（上部）・タイトル・チャプター・レッスン編集
  │     └── セクションを追加ボタン
  │     └── ★ 保存ボタン（下部）← ここに追加
  └── <CourseEnrollments />    ← 受講生一覧
```

`saveCourse` 関数は `CourseEditor` 内に定義されているため、保存ボタンの追加も `CourseEditor.tsx` 内で完結する。

## UI 仕様

- 上部の保存ボタンと同じデザイン・ラベルを使用する
- `saving` 状態・`message` 表示も上部と共通
